# FormatterFree

FormatterFree is a bilingual English / Indonesian browser-based developer toolbox for formatting, validation, conversion, encoding, hashing, minifying, and related utilities.

## Highlights

- 44 developer tools
- English / Indonesian UI
- Dark and light mode
- Browser-side processing for tool input/output
- About Us, Privacy Policy, Terms of Use, and Contact Us pages
- Reserved monetization placements for advertising, affiliate links, or direct sponsors
- Static Vite build suitable for Vercel

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Branding

The active brand is **FormatterFree** with an `FF` logo mark. Legacy FormatDeck and Sociobuzz branding are not used.

## Advertising placeholders

Advertising placements are rendered through generic `ad-slot` containers. They can later be connected to AdSense, affiliate banners, or direct sponsors without restructuring the tool UI.

## Privacy

Tool input and output are processed in the browser by default. Interface preferences such as language and theme may be stored locally in the browser.
